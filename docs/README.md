# docs

Implementation write-ups for features and non-trivial changes across this
monorepo, in English. One file per feature/topic under `docs/features/` —
not a chronological diary, not a duplicate of `git log`.

Write one when a change involves a non-obvious decision, a workaround, or a
constraint future work needs to know about — not for every commit. Keep
entries updated if the feature's behavior changes later; delete the file if
the feature is removed.
